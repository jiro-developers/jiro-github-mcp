# Claude Desktop × GitHub - 처음 시도해볼 질문 모음

설치가 끝났다면 Claude Desktop에 아래 질문들을 그대로 복사·붙여넣기 해서 시도해보세요.

## 시작 전 점검

채팅 입력창 옆 도구 아이콘(슬래시 또는 망치 모양)을 눌러서
**`github`** 항목이 보이는지 확인합니다. 안 보이면 설치가 안 끝났거나 Claude Desktop을
완전히 종료하지 않은 상태입니다.

## 1. 레포 둘러보기

```
dropshot 레포의 README 를 보여줘
```

```
dropshot-server 레포의 최상위 디렉터리에 어떤 폴더가 있는지 알려줘
```

```
jiro-developers 조직에 내가 접근 가능한 레포 목록을 알려줘
```

## 2. 특정 파일 찾기·읽기

```
dropshot-server 에서 docker-compose.yml 파일을 보여줘
```

```
dropshot-server 의 .env.example 같은 파일이 있는지 찾아줘
```

```
dropshot-server 레포에 src/ 폴더가 있는지, 있다면 그 안의 파일 목록을 알려줘
```

## 3. 코드 검색

```
jiro-developers 조직 안에서 "stripe" 라는 단어가 포함된 파일을 찾아줘
```

```
dropshot 레포에서 TODO 주석이 있는 파일을 찾아줘
```

## 4. 변경 이력 (옵션)

PAT에 Pull requests/Issues 권한도 켰다면 아래도 동작합니다.

```
dropshot-server 의 최근 머지된 PR 5개를 요약해줘
```

```
dropshot 의 open 상태 이슈를 라벨별로 묶어서 보여줘
```

## 잘 동작 안 할 때

- "도구를 찾을 수 없습니다" → Claude Desktop을 완전 종료(Cmd+Q) 후 재실행.
- "권한이 없습니다" → PAT 설정에서 해당 레포를 추가했는지, Permissions 가 Read-only 인지 확인.
- "토큰 만료" → 새 PAT 발급 후 `setup.command` 재실행.
- 그래도 안 되면 배포자에게 문의.

## 한 줄 메모를 부탁드려요

1주일간 사용하면서 **자주 쓴 질문 패턴**을 한두 줄씩 적어 배포자에게 보내주세요.
그 데이터로 비개발자에게 더 편한 도구로 다시 만들 예정입니다.

예시:
- "○○ 파일이 누가 만든 건지 보려고 했는데 잘 안 됐다"
- "특정 기능이 어느 파일에 있는지 찾는 게 자주 필요했다"
